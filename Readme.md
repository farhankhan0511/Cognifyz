## Task 1: HTML Structure and Basic Server Interaction
**Objective:** Introduce server-side rendering and basic form submissions.

- Created an HTML structure with forms for user input.
- Set up a basic Node.js server using Express.
- Implemented server-side rendering with EJS to dynamically generate HTML.

**Objective:** Enhance HTML with inline styles and add server-side validation.

- Stored validated data temporarily on the server.
